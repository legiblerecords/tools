# Security

These tools parse untrusted input, and the files they read often hold sensitive security records. If you find a problem that could let a crafted file crash a tool, exhaust its memory, or reach anything outside the file it was given, report it privately rather than in a public issue: use GitHub's private vulnerability reporting on this repository (Security, then "Report a vulnerability").

Expect an acknowledgement within five working days. Please give us a reasonable time to fix a problem before you publish it.

Never include real records, evidence or personal data in a report or an issue. Use invented examples.
